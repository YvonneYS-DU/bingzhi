# 身外化身

这是入口。其余内容按需从这里读。

先立前提：这是术，不是道。然后判定这次要召回哪一具化身，只加载那一层。

`sicheng` 是价值观：判断能不能当下游前提。  
本 skill 是术：把工作台从身体里分出去，接缝时放下，回来或换执行者时再召回。

吸收 J-Space 的控制思想：选择性加载、接缝刷新、账本外化、认识状态、广播枢纽。不训练模型，不改权重，不做 RAG。

认识状态的语义与思诚对齐：`✓` / `?` / `✗` 对应 observed / inferred / unknown。求真纪律仍归思诚。本 skill 不管「该不该信」，只管「此刻点亮什么、放下什么、谁来接着用」。

已有 `memory-manager` 管跨项目草稿。本 skill 管 **当前项目的化身**。不要混写。

## 八奇技里的位置

思诚是道。身外化身是术。

化身不是第二个我，也不是把整座秘境灌进一个身体。每一具化身只带走它要办的那一段：活核、账本、仍在约束动作的 invariant。本体留下 MAP 和身份，供下一具化身寻路。

现在通常只有一具化身：当前会话。  
未来会有多具：不同 agent、不同阶段、不同文件上的并行身体。它们读同一份外化状态，不共享一个塞满的上下文。

召回规则不变：能点名、正在用的才进身体。不是洞观。

## 前提

能点亮的工作台很小。工程问题不是「仓库里有没有这段知识」，而是：

- 正确条目有没有被加载到当前这具化身上
- 约束有没有在机械执行阶段继续保持
- 失败有没有带着诊断交给下一具
- 完成有没有验证覆盖
- 换执行者时，下一具能不能只凭外化状态接着干

记忆带按 **时间尺度、表征密度、刷新义务** 并行存在，没有父子树。同一事实可以同时以不同密度待在两条带上，靠 MAP 互指。

舞台上活着的核，以「此刻能点名、能立刻使用」为准。**不锁死核心数。** 说不出正在用什么，或开始重推导已经写过的约束，才是过载。

## 何时启用

- 打开或回到一个已有项目
- 长任务跨文件、跨轮次、跨会话
- 形成硬约束、关键决策、已验证结论、明确的「不是什么」
- 接缝：子任务完成、即将改文件、即将交付、话题切换
- 长间隔后 resume
- 要把状态交给另一具化身 / 另一个 agent
- 用户说「记住」「别再问这个」「下次接着做」「现在项目什么状态」

## 不要启用

- 一步或一眼能核验的小事
- embedding / 切块 / top-k / 向量召回
- 把对话、diff、工具输出整包写入
- 推测意图、发明概念、未确认事实
- 去改 `memory-manager` 的全局 JSON
- 用本 skill 改写思诚的价值观

## 门控

先分类，用一行记下这次走哪一档，然后只加载这一档需要的东西。把用不到的模块读进来，本身就是选择性失败。

| Pass | 何时 | 加载 |
|---|---|---|
| `fast` | 一步，或一眼能核验 | 不召回化身。做完就走。 |
| `full` | 多步，但边界清楚、一轮能交付 | `identity` 里相关一句；最多再读一条立刻要用的 invariant |
| `loop` | 多阶段、多文件、多轮，换执行者，或状态必须跨接缝活着 | `modules/ledger.md` + `modules/bands.md`；其余按路由表按需读 |

简短输出可以缩短对外回复，不能把验证降到门控底线以下。

任务中途变难，立刻升档。留在 `fast` 只为了省事，是门控失效。

## 接缝上刷新什么

接缝 = 子任务完成、即将调用工具、即将写文件、检查点通过、话题切换、对用户说话之前、把身体交给下一具化身之前。

接缝之间工作。接缝上审计。

| 刷新 | 频率 |
|---|---|
| 账本：Goal / Core / Verified / Open / Next | **每个接缝** |
| 当前活核，以及仍在约束动作的 invariant | 主题一变；红线事件后立刻 |
| identity | 定位变了才读 |
| 当前没用的带和模块 | **永不** |

长间隔之后——压缩、换会话、隔天再来、换 agent——账本还在，前提会淡。先走 `modules/resume.md`，再碰工作。

## 三个寄存器

- **Inner** — 这一具身体里的压缩，只用于想。必须能展开成白话。
- **Ledger** — 身外化身本身。短标注行，每个接缝重读。管状态，不管推理草稿。
- **Outer** — 给人看、给下一具化身看、给任务工具看的完整语言。内部符号不许漏出去。

## 路由

| 这时 | 读 | 带着走 |
|---|---|---|
| 活核说不清，或开始重推导已写过的约束 | `modules/capacity.md` | 此刻真正在用的核 |
| 跨阶段、跨文件、跨轮，或要交给下一具化身 | `modules/ledger.md` | Goal 和 Next |
| 不知道该读哪一带，或一带不够 | `modules/bands.md` | MAP 点名的那一带 |
| 到了接缝，不知道刷新什么 | `modules/seams.md` | 本接缝要动的那几行 |
| 形成了值得留下的事实、决策、失败诊断 | `modules/write.md` | 一句事实 + 认识状态 |
| 长间隔后回来，换执行者，或用户问「上次到哪了」 | `modules/resume.md` | 完整账本，不是最后一行 |

## 不变量

接缝上检查。命中就是发现，不是心情。

1. 活核点不出名，却还在往上下文里堆记忆。
2. 同一约束出现了两个不一致副本，且没有写下这次交换。
3. 失败后又试了一次，没有带着诊断。
4. 某条被叫作 `✓`，却没写验证覆盖。
5. `Next` 空了，账本还假装在用。
6. 把六带整包读进了这一轮。
7. 内部符号漏进了对外回复。
8. 没回读 Goal 就宣布做完。
9. 把整具身体的上下文交给下一具，而不是外化后的账本。

## 存储

项目根目录：

```text
.project-memory/
  MAP.md
  identity.md
  invariants.md
  lessons.md
  ledger.md
  working.md
  traces/
    current.md
    archive/
```

可提交：`MAP.md`、`identity.md`、`invariants.md`、`lessons.md`  
默认不提交：`ledger.md`、`working.md`、`traces/`

模板见 `templates/`。首次启用按模板建空壳，只摘仓库里已经写明的事实，不回填对话。

多具化身仍然读写这一份外化状态。不要为每个 agent 另起一套真相。
