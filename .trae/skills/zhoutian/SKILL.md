# 周天（ZhouTian · 运化流转）

> 始于有作人难见，及至无为众始知。但见无为为要妙，岂知有作是根基。——《悟真篇》

术的前六角度各管一段火候。周天管的是**火候之间的运转**：真气从哪来、往哪去、回到哪、是否循环不息。

炼丹不是六个孤立的步骤，是一炉气在周天里转。写代码也不是六个角度排队上场，是一股「道理」在整个系统里流：道生术、术运角度、观照把经验还道、道再养术。周天就是看这股气流不断的人。

## 大周天

```text
        ┌─────────────────────────────┐
        │            道               │
        │    做人姿态（道生术）         │
        └──────┬──────────────┬───────┘
               │              ▲
        ┌──────▼──────────────┴───────┐
        │            术               │
        │  设计→实现→测试→审查→重构    │
        └──────┬──────────────┬───────┘
               │              ▲
        ┌──────▼──────────────┴───────┐
        │          观照·回流           │
        │    经验 → 教训 → 回炉成道     │
        └─────────────────────────────┘
```

三段循环，缺一段就断流：

1. **道生术**：做人姿态进项目。求真、觉知、外化、洞观不是口号，是写代码时的实际约束。
2. **术运角度**：六角度在项目里周转。设计出蓝图、实现炼成丹、测试验真伪、审查防倾危、重构做温养。
3. **观照还道**：做完一段，观照把经验沉淀成教训，回炉进道。道不是一成不变的，道因做事而更厚。

## 三查（接缝上查）

每个接缝（角度切换、阶段结束、准备交付）检查一次，命中就是断流：

| 查 | 问 | 断流信号 |
|---|---|---|
| 道有没有流进术 | 现在做的事，姿态对吗？还是只顾结果忘了做人 | 为了「快」跳过求真、为了「过」掩盖未知 |
| 术有没有在转 | 六角度是自然周转，还是卡死在某一格 | 反复写不测、反复修不查、反复重写不复盘 |
| 经验有没有还道 | 这段做完了，教训进账了吗 | 结束即散场，下个任务从不记得上场的坑 |

## 何时启用

- 长任务跨多角度、多阶段、多轮次
- 用户说「整个过程怎么样」「是不是走偏了」「哪里卡住了」
- 多个角度串行时，检查衔接是否顺
- 一段收尾时，检查教训是否已回流
- 感觉「一直在忙但没长进」时

## 何时不启用

- 单角度任务：周天不管单炉火候，那是角度自己的事
- 已经在某个角度内部工作：不绕回来检查循环
- 只是问一步怎么改：直接做

## 和 shenwai 的分工

- `shenwai` 管**这具化身带什么走**：账本、接缝、换执行者。是任务状态的流转。
- `zhoutian` 管**道理往哪流**：道术循环、经验回流。是气机的流转。
- 状态可以交给下一具化身；道理必须流回道，不能停在外层。

周天是术的脉搏：不直接炼丹，但看得到整炉气是不是活的。
